# RedLamp

Aplicación Android para controlar bombillas MOES mediante Matter en la red local. Permite ajustar brillo y temperatura, programar horarios y usar un temporizador.

[Descargas en GitHub Releases](https://github.com/magiclab-coding/red-lamp/releases) · [Compilación y pruebas](COMPILAR.md) · [Flujo de desarrollo](AGENTS.md)

La versión de prueba 5.3 incorpora la dirección del repositorio red-lamp. Instálala sobre la versión anterior para conservar las bombillas vinculadas. En Información puedes activar las versiones de prueba.

El código mantenido está en `android/studio`. La base binaria de compilación aporta el controlador Matter y las bibliotecas ARM64. El código propio se distribuye bajo la licencia MIT.
